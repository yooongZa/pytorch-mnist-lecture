# PyTorch MNIST 예측과 손실

한국어 50분 강의 자료입니다. 1280×720 고정형 20페이지와 교차 엔트로피 코드 해설 5페이지로 구성했습니다.

- [전체 강의](https://yooongza.github.io/pytorch-mnist-lecture/)
- [교차 엔트로피 코드 해설](https://yooongza.github.io/pytorch-mnist-lecture/cross-entropy.html)

좌우 방향키와 하단 번호로 페이지를 이동합니다. 설명용 확률·가중치는 직접 정한 값으로 표시했습니다. 공개 웹에서는 저장된 PyTorch 실행 결과를 표시하며, 확률 그래프와 퀴즈는 브라우저에서 작동합니다.

교차 엔트로피 예제는 `python cross-entropy-example.py`로 실행할 수 있습니다. Python과 PyTorch가 필요합니다.

주교재: [PyTorch 한국어 튜토리얼](https://tutorials.pytorch.kr/beginner/basics/intro.html)

공개용 파일은 직접 작성한 강의와 예제 코드이며, 원본 LMS 자료는 포함하지 않습니다.
