01 · 확률 준비

3개 상황 × 숫자 후보 10개

각 행이 한 상황입니다. 열 번호 0~9는 숫자 후보입니다.

torch.full((3, 10), 0.01)로 모든 칸을
우선 1%로 채운 뒤, 각 상황에 맞게 바꿉니다.

02 · 손실 함수의 입력
만든 확률을 손실 함수에 연결합니다
CrossEntropyLoss(교차 엔트로피 손실)는 점수와 정답 번호를 받습니다.

 
case_logits = case_probs.log()
case_y = torch.tensor(
    [7, 7, 7], dtype=torch.long
)
.log()는 위 표의 확률을
재현하는 Logits(로짓)를 만듭니다.
이 점수에 Softmax(소프트맥스)를 적용하면
직접 정했던 확률로 돌아옵니다.

 
이 예제의 준비 순서
직접 정한 확률 → log() → 설명용 점수
실제 모델에서의 순서
모델의 마지막 Linear → 출력 점수
[7, 7, 7]은
“세 상황의 정답이 모두 7”이라는 뜻입니다.

 
실제 모델에서는 마지막 Linear의 출력 점수를 CrossEntropyLoss에 전달합니다.03 / 05





 
03 · 출력 해석
세 손실을 따로 보고, 평균도 봅니다
아래 코드를 PyTorch에서 실행해 확인한 결과입니다.

 
"""설명용으로 직접 정한 확률 세 가지를 비교합니다."""
import torch
from torch import nn

# 비교를 위해 직접 만든 확률입니다. 실제 모델의 출력이 아닙니다.
case_probs = torch.full((3, 10), 0.01)
case_probs[0] = 0.60 / 9
case_probs[0, 7] = 0.40
case_probs[1] = 0.10 / 9
case_probs[1, 7] = 0.90
case_probs[2, 3] = 0.91

# 위 확률을 재현하는 점수를 준비합니다.
case_logits = case_probs.log()
case_y = torch.tensor([7, 7, 7], dtype=torch.long)
case_losses = nn.CrossEntropyLoss(reduction="none")(case_logits, case_y)
case_mean_loss = nn.CrossEntropyLoss()(case_logits, case_y)

print("확률 합:", case_probs.sum(dim=1))
print("예측 클래스:", case_logits.argmax(dim=1))
print("개별 손실:", case_losses)
print("평균 손실:", round(case_mean_loss.item(), 4))
print("직접 계산:", -case_probs[:, 7].log())

Python 코드 받기
버튼을 누르면 실제 실행해 저장한 출력이 표시됩니다.
reduction="none": A·B·C 각각의 손실
기본 설정: 세 손실의 평균
argmax(dim=1): 각 행에서 가장 큰 점수의 숫자
-case_probs[:, 7].log():
정답 7의 확률로 직접 계산해 같은 값인지 확인
